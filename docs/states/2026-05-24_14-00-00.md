## 1. 项目概述

PixelPainting 是一个实时协作的像素艺术教学平台，核心功能是将学生的笔触作品聚合成马赛克艺术效果。教师可以创建房间，学生可以上传笔触，最终形成一幅完整的参考图动画。

### 1.1 核心功能

1. **笔刷组管理**: 创建、编辑、存储笔刷预设（10级亮度）
2. **实时渲染**: WebGL 粒子渲染系统，将笔刷聚合成图像
3. **动画系统**: 基于 GSAP Timeline 的笔刷动画脚本控制系统
4. **房间协作**: 教师创建房间，学生加入并提交作品
5. **参考图系统**: 支持多张参考图序列，用于动画Formation

### 1.2 技术栈

- **前端框架**: Next.js 16 (App Router)
- **实时通信**: Supabase Realtime
- **3D渲染**: Three.js (InstancedMesh)
- **动画引擎**: GSAP Timeline
- **数据库**: Supabase PostgreSQL
- **样式**: Tailwind CSS

### 4.2 BrushChoreographer - 笔刷动画编舞器

管理所有笔刷动画形式：

| 动画形式 | 说明 | 关键参数 |
|----------|------|----------|
| `swirlBrushes` | 螺旋动画 | centerX, centerY, radius, speed, direction |
| `aerialDance` | 空中舞蹈 | height, frequency, phase, amplitude |
| `orbitAroundAxis` | 轴 orbit | axis, radius, speed, heightAmplitude |
| `flyAlongBezier` | 贝塞尔曲线 | controlPoints, duration |
| `randomRoamBrushes` | 随机漫游 | speed, amplitude, rotationSpeed |
| `rotateBrush` | 单一旋转 | axis, anglePerSecond, phase |

### 4.3 CameraController - 摄影机控制器

支持多种摄影机模式：

```typescript
type CameraMode = 'fixed' | 'follow' | 'orbit' | 'orbitBrush' | 'orbitArray';
```

- **固定模式**: 静止视角
- **跟随模式**: 跟随目标
- **环绕模式**: 环绕原点或笔刷

### 4.5 ScriptParser - 动画脚本解析器

支持 DSL 脚本格式：

```
# 格式: 指令 参数 time: 秒数 [duration: 秒数]

CAMERA position: {0, 0, 1000} lookAt: {0, 0, 0} time: 0 fov: 60
BRUSH_FLIGHT duration: 3 scatter: 800 time: 0 direction: left
FORMATION type: reference index: 0 time: 4 duration: 3
```

**支持命令**: CAMERA_MOVE, CAMERA_ZOOM, BRUSH_FLIGHT, FORMATION, RANDOM_ROAM, SWIRL, AERIAL_DANCE, ORBIT_AXIS, WAVE, OSCILLATE, PULSE, ARRAY_ROTATE, ARRAY_SCALE, EXPLOSION, IMPLOSION, COLOR_FLASH, STROBE
